# **Supply Chain Data Exchange Standard (SC-DEX)**

Welcome to the official documentation for the **Supply Chain Data Exchange Standard (SC-DEX)**. SC-DEX is an open data standard developed to streamline and enhance data exchange across supply chains, allowing organizations to better manage and share information on locations, relationships, and activities. Here, you’ll find a complete guide to understanding and implementing SC-DEX, including schema details, governance, extension possibilities, and community engagement.
